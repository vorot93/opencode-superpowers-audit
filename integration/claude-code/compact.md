## superpowers-audit after compaction

Compaction drops hook-added context. If you are mid-way through `superpowers:brainstorming` or
`superpowers:writing-plans`, use the Skill tool to reload that skill once; its audit stage returns
with it. Then continue from where you were; do not restart that skill's checklist. Before
dispatching or continuing an audit, reload `superpowers-audit:superpowers-audit` with the Skill tool
for its dispatch and configuration context. An in-progress audit continues under the shared skill's
interruption rules: same auditor session, and do not resend a delivered round.
